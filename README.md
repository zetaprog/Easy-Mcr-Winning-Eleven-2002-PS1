# Easy-Mcr-Winning-Eleven-2002-PS1

Easy MCR is a tool for editing Memory Cards (.MCR) from Winning Eleven 2002 / ISS Pro Evolution 2 on PlayStation 1.

The program allows you to create, edit and manage players, formations, attributes, appearances and team data with modern football database support.

## Features

- Create and edit players
- Edit formations and lineups
- Read and write player stats and skills
- Read and write training data
- Drag & drop players with the mouse
- Local appearance database system
- Faces database support
- Export database to JSON
- Formation editor integrated into the MCR menu
- Browser and code optimization
- Various interface improvements

## Modern Database Support

Easy MCR includes integration with modern football databases and websites:

- Transfermarkt
- Sofifa
- FMInside (including FM26 database support)
- PESMaster / eFootball database

## Conversion Features

- Convert FC25 stats to Winning Eleven 2002
- PES6 to WE2002 stat conversion
- Customizable attribute conversion system
- Player data importing assistance
